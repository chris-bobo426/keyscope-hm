# 赛事要求与交付

依据：[第五届华秦杯创意作品赛官方指南](https://huaqin.xidian.edu.cn/2026/04/01/第五届“华秦杯”网络安全创新大赛创意作品赛参赛指南/)；[本地快照](downloads/competition/guide.html)。2026-10-29 又检查了[官网文章目录](https://huaqin.xidian.edu.cn/archives/)，所见最新本届指南仍为 2026-04-01 发布；未发现后续改期公告。这仅限已查询的官方页面，不代替报名系统通知。

| 项目 | 官方指南所述 |
|---|---|
| 报名截止 | 2026-11-08 24:00 |
| 材料 | 指南表述为 11月8日前提交作品相关材料；报名与交材料应分别核对系统状态 |
| 初评 | 11月9日至13日 |
| 入围通知阶段 | 11月14日至17日 |
| 决赛 | 暂定11月21日 |
| 答辩 | 总计10分钟，包含演示及问答；需准备源码查验 |
| 主要交付 | 系统设计、测试方案/数据/结果分析、相关文档、知识产权及技术披露相关声明 |
| 奖项 | 一等奖1项、二等奖2项、三等奖3项 |

对本项目的直接要求：材料应展示“问题—实现—可复现样例—对比结果—边界”，并让源码、报告数字与现场演示指向同一冻结版本。复用外部基准、框架和官方示例时说明出处及自己的增量。

建议内部把11月7日设为材料冻结日，留出报名系统校验时间；这是项目排期建议，不是官方新截止日。具体开发顺序见 [05](05-实验方案与启动门槛.md)。

尚未做：本次没有登录参赛系统、检查团队报名状态或上传材料。
